# Longevity Icons

111 open source icons for longevity and evidence-first biohacking: circadian
rhythms, sleep, biomarkers, vitals, training zones, supplement stacks,
recovery modalities, protocol tracking, and the study-design vocabulary
(cohorts, placebo arms, error bars, n-of-1) that separates a protocol from
anecdote. One outline style drawn on a 24px grid with a 2px stroke. Every
icon inherits `currentColor`, so it takes your text color with no extra
styling.

Categories: Rhythms, Sleep, Biomarkers, Vitals, Fitness, Nutrition, Recovery, Protocols, Aging, Evidence.

## Usage

SVGs live in `icons/`, one file per icon. The set is also packaged as a
single IconifyJSON file, `longevity.json`, which is the format
[Iconify](https://iconify.design) and most icon frameworks consume.
